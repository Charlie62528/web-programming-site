Introduction

The World Wide Web is an information system built on top of the Internet, giving users the ability to access and link documents and resources through web browsers. It was created at CERN by Tim Berners-Lee and developed using core technologies such as HTML, HTTP, and URLs. It began as a tool for sharing scientific information and has evolved into a dynamic platform that supports communication, applications, and commerce.

Key Milestones in the History of the Web

1945 - Memex Information System

The memex, first proposed by Vannevar Bush in his 1945 essay "As We May Think," is a theoretical device that aimed to enhance human memory and knowledge by allowing people to store and recall information in a mechanical way.

How Vannevar Bush's Memex and Ted Nelson's Hypertext Shaped Information Science and the Internet

1965 - Hypertext

In 1965, Ted Nelson published “Complex Information Processing : A file Structure for the Complex , the Changing , and the Indeterminate”. In this paper Nelson coined the term hyper text and hypermedia to refer to features of a computerized information system. Hypertext became oneof the Web's foundational concepts.

Ted Nelson - History of Information

1980 - ENQUIRE

ENQUIRE was a software project written in 1980 by Tim LEE at CERN , which was the predecessor to the world wide web It was a simple hypertext program that had some of the same ideas as the Web and the Semantic web but was different in several important ways.

ENQUIRE - Everything Explained Today

1989 - Berners-Lee's Proposal

In 1989, Berners-Lee submitted Information Management: A Proposal at CERN, the proposal described a global hypertext system for connecting and sharing information between computers. It is generally considered the beginning of the World Wide Web.

The birth of the Web – Home | CERN

1990 - Web Proposal

In 1990, Berners-Lee and Robert Cailliau formalized the Web proposal. Berners-Lee then developed the first browser, server, and website. This transformed the Web from a proposal into a functioning system based on HTML, HTTP and URLs.

The birth of the Web – Home | CERN

1990 - First Web Server

The first web server, httpd, and browser-editor, WorldWideWeb, became operational at CERN. The server delivered documents, while the browser allowed users to view and edit linked information. The first website was created at info.cern.ch. It explained the World Wide Web project and provided instructions for creating servers and webpages.

The birth of the Web – Home | CERN

1991 - Public Release

In 1991, Berners-Lee announced the Web project to Internet discussion groups. The Web became available beyond CERN, allowing researchers and programmers elsewhere to create servers and websites.

The birth of the Web – Home | CERN

1993 - Mosaic Browser

In 1993, The National Center for Supercomputing Applications released the Mosaic browser, its graphical and relatively user-friendly interface helped make the Web accessible to people outside technical research communities.

The birth of the Web – Home | CERN

1993 - Web in Public Domain

CERN placed its Web software in the public domain. Organizations and individuals could use and improve Web technology without paying royalties, supporting rapid and open adoption

The birth of the Web – Home | CERN

1994 - W3C Founded

In October 1994, Sir Tim Berners-Lee founded the World Wide Web Consortium (W3C) at the Massachusetts Institute of Technology, Laboratory for Computer Science [MIT/LCS] in collaboration with CERN, where the Web originated with support from DARPA and the European Commission. W3C coordinated open Web standards so that websites could work across different browsers, computers, and organizations.

History | About us | W3C

1994 - Netscape Navigator

Netscape Navigator was released. It helped bring the Web into homes and businesses and became one of the first widely used commercial browsers.

Servers: Hidden Engines of the Web - CHM Revolution

1995 - JavaScript

In 1995, JavaScript was developed at Netscape, which allowed webpages to respond to users and change dynamically, helping the Web evolve from static documents into interactive applications.

ECMAScript® 2027 Language Specification

1995 - Internet Explorer

Microsoft released Internet Explorer. The competition between Internet Explorer and Netscape accelerated browser development, although incompatible features also created problems for Web developers.

Internet Explorer - Britannica

1996 - CSS

In 1996, W3C published CSS Level 1 as a Web standard, CSS separated a webpage’s presentation—such as fonts, colors, and margins—from its HTML content, making website design more flexible and consistent.

Cascading Style Sheets, level 1

1996 - Website Saving

The Internet Archive began preserving websites, ensuring that Webpages could be accessed even if they changed or disappeared; Web archiving made it possible to preserve part of the Web’s historical record.

About IA

1997 - JavaScript Standards

1997, JavaScript was standardized internationally as ECMAScript. Standardization gave browser developers a common specification for implementing the language.

ECMAScript® 2027 Language Specification

1998 - Google Founded

In 1998, Google was founded. Its link-based search and ranking methods helped users find relevant pages as the Web expanded rapidly.

How we started and where we are today - Google - About Google

1999 - Web Content Accessibility Guidelines (WCAG)

1999, W3C published the Web Content Accessibility Guidelines 1.0, The guidelines established recommendations for making Web content more accessible to people with disabilities.

Web Content Accessibility Guidelines 1.0

2001 - Wikipedia

Wikipedia was launched, it demonstrated that large communities could collaboratively create and maintain knowledge directly through the Web.

Wikipedia timeline - Meta-Wiki

2001 - WayBack Machine

The Wayback Machine became publicly accessible, it allowed users and researchers to access archived versions of websites and study how the Web changed over time.

Internet Archive - Wayback Machine

2004 - WHATWG

In 2004, The WHATWG was formed to continue developing HTML and Web-application technologies. Its work helped move HTML toward features needed for interactive applications, eventually contributing to HTML5.

FAQ — WHATWG

2004-2006 - Facebook, YouTube

Between 2004-2006, Facebook and YouTube appeared during the expansion of social media. The Web increasingly became a platform where ordinary users created, shared, and discussed content.

Company Info

2005 - Google Maps

In 2005, Google Maps introduced a highly interactive browser-based mapping experience. It demonstrated how Web technologies could deliver application-like experiences without traditional desktop software.

Official Google Maps news and updates | Google Blog

2007 - iPhone

In 2007,the iPhone brought a capable web browser to a widely adopted mobile device, This helped accelerate the transition from a desktop-centred Web to a mobile Web.

Apple Reinvents the Phone with iPhone - Apple

2008 - Google Chrome

In 2008, Google chrome was released. Chrome intensified browser competition and emphasized speed, security, and support for complex Web applications.

Google Chrome - A Fresh Take on the Browser

2014 - HTML5

In 2014, W3C published HTML5 as a formal recommendation. HTML5 added standardized support for audio, video, graphics, and application features, reducing dependence on browser plug-ins.

HTML Standard

Between 2015 and 2016 - Let's Encrypt certificates

Let’s Encrypt began providing free, automated security certificates. It reduced the cost and difficulty of implementing HTTPS, helping encrypted Web connections become common.

About Let's Encrypt

2019 - Single version of HTML

W3C and WHATWG agreed to collaborate on a single version of HTML. This reduced conflict between competing HTML specifications and established the continuously updated HTML Living Standard.

W3C and the WHATWG signed an agreement to collaborate on a single version of HTML and DOM | 2019 | News | W3C

2020 - Progressive Web Apps

Progressive Web Apps, browser-based collaboration, streaming and cloud applications continued expanding. The browser increasingly became a platform for software that once required separate desktop programs.

Web Applications | Working Groups | Discover W3C groups | W3C

Three Key Technologies of the Web

HTML

HTML defines the structure and content of web pages.

HTTP

HTTP allows web browsers and servers to communicate and exchange information.

URL

A URL provides the address used to locate and access resources on the Web.
