Introduction

The World Wide Web is an information system built on top of the Internet. It allows people to access and connect documents and other resources through web browsers. Tim Berners-Lee created it at CERN using three core technologies: HTML, HTTP and URLs. What began as a system for sharing scientific information evolved into a platform for communication, publishing, commerce and software applications.

Key Milestones

1945 - The Memex Concept (Source: The Atlantic)

Vannevar Bush described the theoretical Memex device in his essay As We May Think. It would help people store and retrieve information through associative trails.

Why it mattered: Although it was never built, the Memex anticipated the idea of connecting documents through links.

1965 - Hypertext (Source: History of Information)

Ted Nelson published Complex Information Processing: A File Structure for the Complex, the Changing and the Indeterminate and used the terms hypertext and hypermedia.

Why it mattered: Documents connected through links became one of the Web's central concepts.

1980 - ENQUIRE (Source: W3C)

Tim Berners-Lee developed ENQUIRE at CERN. This experimental hypertext program connected information through linked pages and anticipated some ideas later used by the Web.

Why it mattered: It gave Berners-Lee practical experience with linked information systems before he proposed the Web.

1989 - The Web Is Proposed (Source: CERN)

Berners-Lee submitted Information Management: A Proposal at CERN, describing a global hypertext system for connecting and sharing information among computers.

Why it mattered: The proposal is generally considered the beginning of the World Wide Web.

1990 - The First Browser, Server and Website (Source: CERN)

Berners-Lee and Robert Cailliau formalized the Web proposal. Berners-Lee then developed the first web server, httpd, and the browser-editor WorldWideWeb. The first website at info.cern.ch explained the project and how to create servers and webpages.

Why it mattered: HTML, HTTP and URLs transformed the Web from a proposal into a functioning system.

1991 - The Web Opens Beyond CERN (Source: CERN)

Berners-Lee announced the Web project through Internet discussion groups.

Why it mattered: Researchers and programmers outside CERN could begin creating their own servers and websites.

1993 - Mosaic and an Open Web (Sources: NCSA; CERN)

The National Center for Supercomputing Applications released the Mosaic graphical browser. In the same year, CERN placed its Web software in the public domain and later made it available under an open licence.

Why it mattered: Mosaic made the Web approachable, while CERN's decision allowed anyone to use and improve its technology without royalties.

1994 - W3C and Netscape Navigator (Sources: W3C; Computer History Museum)

Tim Berners-Lee founded the World Wide Web Consortium at MIT in collaboration with CERN. Netscape Navigator was also released and became one of the first widely used commercial browsers.

Why it mattered: W3C coordinated open standards, while Netscape helped bring the Web into homes and businesses.

1995 - JavaScript and Internet Explorer (Sources: Ecma International; Encyclopaedia Britannica)

Brendan Eich developed JavaScript at Netscape, allowing webpages to respond to users and change dynamically. Microsoft also released Internet Explorer.

Why it mattered: JavaScript helped turn static documents into interactive experiences, while browser competition accelerated development.

1996 - CSS Level 1 and Web Archiving (Sources: W3C; Internet Archive)

W3C published CSS Level 1, separating presentation from HTML content. The Internet Archive also began preserving websites.

Why it mattered: CSS made design more flexible and consistent, while archiving preserved parts of the Web that could otherwise disappear.

1997 - ECMAScript Standard (Source: Ecma International)

JavaScript was standardized internationally under the name ECMAScript.

Why it mattered: A common specification helped browser developers implement the language more consistently.

1998 - Google (Source: Google)

Google was founded and developed link-based methods for ranking search results.

Why it mattered: Improved search helped users find relevant webpages as the Web expanded rapidly.

1999 - Web Accessibility Guidelines (Source: W3C)

W3C published the Web Content Accessibility Guidelines 1.0.

Why it mattered: The guidelines established recommendations for making web content accessible to people with disabilities.

2001 - Wikipedia and the Wayback Machine (Sources: Wikimedia Meta-Wiki; Internet Archive)

Wikipedia launched as a collaboratively maintained encyclopedia. The Internet Archive's Wayback Machine also became publicly accessible.

Why it mattered: One project demonstrated collaborative knowledge creation, while the other allowed people to explore archived versions of websites.

2004 - WHATWG (Source: WHATWG)

The Web Hypertext Application Technology Working Group was formed to develop HTML and technologies needed by web applications.

Why it mattered: Its work contributed to HTML5 and the modern HTML Living Standard.

2004 to 2006 - The Social Web (Sources: Meta; YouTube)

Facebook, YouTube and Twitter appeared during the rapid expansion of social media.

Why it mattered: The Web became a participatory platform where ordinary users created, shared and discussed content.

2005 - Google Maps (Source: Google)

Google Maps introduced a highly interactive mapping experience inside a browser.

Why it mattered: It showed that websites could behave like sophisticated desktop applications.

2007 - The Mobile Web Accelerates (Source: Apple)

The iPhone placed a capable web browser on a widely adopted mobile device.

Why it mattered: It accelerated the transition from a desktop-centred Web to a mobile Web.

2008 - Google Chrome (Source: Google)

Google released Chrome with an emphasis on speed, security and support for complex applications.

Why it mattered: Chrome intensified browser competition and helped advance the browser as an application platform.

2014 - HTML5 Recommendation (Source: W3C)

W3C published HTML5 as a formal recommendation.

Why it mattered: HTML5 standardized audio, video, graphics and application features, reducing dependence on browser plug-ins.

2015 to 2016 - Let's Encrypt (Source: Let's Encrypt)

Let's Encrypt began issuing free, automated digital certificates for websites.

Why it mattered: It reduced the cost and difficulty of enabling HTTPS, helping encrypted web connections become common.

2019 - One HTML Standard (Source: W3C)

W3C and WHATWG agreed to collaborate on a single version of HTML and the Document Object Model.

Why it mattered: The agreement reduced conflict between specifications and established the continuously updated HTML Living Standard.

2020 and Beyond - The Browser as a Software Platform (Source: W3C Web Applications Working Group)

Progressive Web Apps, browser-based collaboration, streaming services and cloud applications continued to expand.

Why it mattered: The browser increasingly became a platform for software that once required separate desktop programs.

Three Key Web Technologies

HTML
Defines the structure and meaning of a webpage's content.
HTTP
Allows web browsers and servers to communicate and exchange resources.
URL
Provides the address used to locate and access a resource on the Web.

The Web Uses the Internet

The Web is not the Internet itself. It is a linked information system that uses the Internet's networking infrastructure. A browser requests a resource identified by a URL, usually communicates with a server through HTTP or HTTPS, and interprets the returned HTML.
