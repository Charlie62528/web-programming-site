History of the World Wide Web

From the idea of hypertext to an open, interactive, secure, and mobile platform for global information and applications.

What is the World Wide Web?

The World Wide Web is an information system built on top of the Internet. It allows users to access and link documents and resources through web browsers. Created at CERN by Tim Berners-Lee, it uses core technologies such as HTML, HTTP, and URLs. It began as a system for sharing scientific information and developed into a platform supporting communication, applications, and commerce.

Key milestones

1945

The Memex concept

In “As We May Think,” Vannevar Bush described a theoretical device for storing and recalling information through associative trails.

Why it mattered: Although never built, Memex anticipated the idea of connecting documents through links.

Source: “As We May Think”
1965

Hypertext receives its name

Ted Nelson coined the terms “hypertext” and “hypermedia” while describing computerized information structures.

Why it mattered: Documents connected through links became one of the Web’s central concepts.

Source: History of Information
1980

ENQUIRE at CERN

Tim Berners-Lee created ENQUIRE, a small hypertext program that connected information about people, projects, and software.

Why it mattered: ENQUIRE explored concepts that later reappeared in the World Wide Web.

Source: CERN
1989

The Web is proposed

Berners-Lee submitted “Information Management: A Proposal” at CERN, describing a global hypertext system for sharing information between computers.

Why it mattered: The proposal is generally considered the beginning of the World Wide Web.

Source: CERN
1990–1991

The first working Web

Berners-Lee and Robert Cailliau formalized the proposal. The first server, browser-editor, and website at info.cern.ch became operational. In 1991, the Web was announced beyond CERN.

Why it mattered: HTML, HTTP, and URLs transformed a proposal into a functioning system that others could join.

Source: The first website
1993

Mosaic and an open Web

NCSA released the graphical Mosaic browser, and CERN placed its Web software in the public domain.

Why it mattered: A user-friendly browser and royalty-free technology accelerated adoption outside research institutions.

Source: CERN
1994

W3C and Netscape Navigator

Berners-Lee founded the World Wide Web Consortium. Netscape Navigator also helped bring the Web into homes and businesses.

Why it mattered: Open standards helped websites work across different browsers, computers, and organizations.

Source: W3C history
1995–1997

The interactive Web stack develops

JavaScript appeared at Netscape in 1995, W3C published CSS Level 1 in 1996, and JavaScript was standardized as ECMAScript in 1997.

Why it mattered: Structure, visual presentation, and interactive behavior became separate building blocks for richer webpages.

Source: W3C CSS Level 1
1996–2001

The Web gains a memory

The Internet Archive began preserving websites in 1996, and the Wayback Machine became publicly accessible in 2001.

Why it mattered: Archived versions preserve webpages that may otherwise change or disappear.

Source: Internet Archive
1998–2001

Search and collaborative knowledge

Google’s link-based ranking helped users find relevant pages as the Web expanded. Wikipedia then demonstrated large-scale collaborative publishing.

Why it mattered: The Web became easier to search and easier for communities to create.

1999

Web accessibility guidance

W3C published the Web Content Accessibility Guidelines 1.0.

Why it mattered: The guidelines established recommendations for making Web content accessible to people with disabilities.

Source: WCAG 1.0
2004–2006

Web applications and social media

WHATWG formed to advance HTML and application technologies. Facebook, YouTube, Twitter, and Google Maps illustrated the rise of user-created content and interactive browser applications.

Why it mattered: The Web evolved from linked documents into a participatory software platform.

Source: WHATWG
2007–2008

The mobile and high-performance Web

The iPhone brought a capable browser to a widely adopted mobile device. Google Chrome then increased browser competition around speed, security, and application support.

Why it mattered: The Web expanded beyond desktop computers, while browsers became more powerful application platforms.

Source: Google Chrome launch
2014

HTML5 becomes a recommendation

W3C published HTML5 as a formal recommendation, standardizing audio, video, graphics, and application features.

Why it mattered: Webpages could provide rich experiences with less dependence on proprietary browser plug-ins.

Source: W3C HTML5 Recommendation
2015–2016

HTTPS becomes easier to adopt

Let’s Encrypt began providing free, automated security certificates.

Why it mattered: It reduced the cost and difficulty of encrypting Web connections.

Source: Let’s Encrypt
2019–2020

One HTML standard and richer applications

W3C and WHATWG agreed to collaborate on a single version of HTML and the DOM. Progressive Web Apps, streaming, cloud tools, and browser collaboration continued to expand.

Why it mattered: The browser increasingly became a platform for software that previously required separate desktop programs.

Source: W3C–WHATWG agreement

Three key Web technologies

HTML

Defines the structure and content of webpages.

HTTP

Allows web browsers and servers to communicate and exchange information.

URL

Provides the address used to locate and access a resource on the Web.
